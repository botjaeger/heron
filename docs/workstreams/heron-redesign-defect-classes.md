# Heron redesign — defect classes

The redesign (menu bar variants, overview, hover panels, histories, Settings window) has its own
ledger; the classes from before it are in `heron-defect-classes.md`. One row per class: the rule,
the guard that fails when a new site breaks it, and every site found. Before a sweep, re-check
every class here and there across the whole app. Guards live in
`Tests/HeronUITests/SweepGuardTests.swift` unless named otherwise.
